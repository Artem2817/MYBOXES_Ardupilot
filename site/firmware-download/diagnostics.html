2. Прошейте плату

Откройте HEX в STM32CubeProgrammer и загрузите через DFU. После записи снимите BOOT0 / отпустите BOOT и перезапустите плату. При запуске зелёный LED должен мигать.

3. Запустите приложение

Скачать EXE для Windows

Слева — положение платы. Справа — шесть блоков автоматической проверки. Подробности открываются в постоянной панели. Графики IMU, барометров и питания — в меню «•••».

Один файл, без установки Python. Подключите плату по USB и выберите COM-порт. Проверки запустятся автоматически; кнопка «Проверить» повторит цикл.

Справка

Программа 0.2.2 совместима с HEX 0.2.1: если он уже установлен, достаточно обновить EXE. Полный HEX записывает загрузчик с 0x08000000 и приложение с 0x08020000; последние сектора параметров не включены. Используйте только файл своей ревизии.

LED мигает, пока прошивка работает. В приложении остаются только автоматические проверки: IMU, барометры, SD-карта, Flash, USB и регистр OSD. SD-тест создаёт, проверяет и удаляет отдельный временный файл, сохраняя существующие файлы.

При кратком обрыве приложение ожидает ту же USB-плату и учитывает смену номера COM. Журнал сеанса сохраняется. Если подключение не возвращается, переподключите USB.

Если COM-порта нет: проверьте кабель с передачей данных, снимите BOOT0 после записи, перезапустите плату. Если доступен только DFU, повторите запись полного HEX своей платы. Не меняйте защиту MCU и option bytes без необходимости.

Зелёный статус относится к перечисленным автоматическим проверкам. Электрические выходы и видеотракт этим циклом не проверяются. На графиках показаны физические единицы и последние 10, 30 или 60 секунд; пауза останавливает просмотр, запись продолжается.
