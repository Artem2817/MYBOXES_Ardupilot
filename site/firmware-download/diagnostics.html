2. Прошейте плату

Откройте HEX в STM32CubeProgrammer и загрузите через DFU. После записи снимите BOOT0 / отпустите BOOT и перезапустите плату. При запуске зелёный LED должен мигать.

3. Запустите приложение

Скачать EXE для Windows

Один файл, без установки Python. Подключите плату по USB, выберите COM-порт и нажмите «Полная диагностика».

Перед активными проверками выходов снимите пропеллеры и отключите опасные нагрузки. Полное стирание чипа для записи HEX не требуется.

Справка

Версия 0.2.0. Полный HEX записывает загрузчик с 0x08000000 и приложение с 0x08020000; последние сектора параметров не включены. Используйте только файл своей ревизии.

LED мигает, пока программа работает. Для отдельной проверки выберите led.visual: он должен светиться постоянно во время теста, затем вернуться к миганию. Успех подтверждает оператор.

Если COM-порта нет: проверьте кабель с передачей данных, снимите BOOT0 после записи, перезапустите плату. Если доступен только DFU, повторите запись полного HEX своей платы. Не меняйте защиту MCU и option bytes без необходимости.

Внешние проверки подскажут, что подключить. Встроенный self-test IMU и активный нагрев пока не реализованы; такие шаги не отмечаются успешными. Диагностический PWM не является тестом DShot. Сборка и программные проверки пройдены; физическая приёмка новых образов ещё требуется.
